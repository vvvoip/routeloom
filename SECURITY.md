# Security policy

RouteLoom is pre-alpha and has no production-supported release. Do not deploy the current server scaffold as a public proxy.

Do not post credentials, browsing histories, private network details, or exploitable vulnerability details in public issues. If GitHub private vulnerability reporting is enabled, use Security → Report a vulnerability. Otherwise open a minimal issue requesting a private contact channel without sensitive details; maintainers will arrange one.

Future release requirements include authenticated clients, certificate validation, device revocation, authenticated local IPC, least-privilege OS helpers, server egress authorization, protected cloud metadata, sanitized diagnostics, signed updates, and DNS/IPv6 leak tests.
